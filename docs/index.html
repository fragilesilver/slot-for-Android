Installing

  1. Download the APK

    Grab slot-android.apk from the latest release on your phone. It needs a 64-bit ARM (arm64) device on Android 8.0 or newer.

  2. Install it

    Open the downloaded file. Android will ask you to allow installs from your browser or file manager the first time.

  3. Allow All files access

    Open slot. When asked, turn on All files access. slot then keeps everything in /sdcard/slot/, where a file manager or a USB cable can reach it.

  4. Add your games

    Put your legally obtained ROMs in Games/GBA, Games/GB and Games/GBC inside /sdcard/slot/. Or use Library › Import games from Downloads in the shelf menu to pull them in from your Download folder.

    ROMs must be unzipped!

    The shelf does not read .zip or .7z files. Library's import is the exception: it unpacks zips from Download for you.

  5. Open slot again and play!

    The shelf is built when the app starts, so reopen it after adding files by hand.

  1. Back up first

    In the shelf menu, open Library › Back up now. It zips your saves, states, cheat toggles and cart colours into Backups/.

  2. Install the new APK over the old one

    Download the latest release and open it. Android updates the app in place. Your games, saves, states, labels and settings live in /sdcard/slot/ and are left alone.

"App not installed"?

An APK signed with a different key (for example one you built yourself) can't update an existing install. Uninstall slot, install the new APK, then use Library › Restore if anything is missing.

  1. Get the toolchain

    Rust (the version pinned in rust-toolchain.toml), cargo-apk, cargo-ndk, Android NDK r27 and a JDK.

  2. Build the emulator cores

    Build mGBA and gpSP for Android with cores/mgba/build-android.sh and cores/gpsp/build-android.sh, into crates/slot/android-libs/arm64-v8a/. Without them slot runs a test pattern instead of games.

  3. Build and install

    android/build.sh run builds a debug APK, installs it on the connected device and launches it.

    SLOT_RELEASE=1 android/build.sh run builds a release signed with ~/.android/slot-release.jks.

Full details are in ANDROID.md.

User guide

  1. Browse the Shelf

    Left and Right flip through the carts.
    L and R switch platforms.
    Up / Down jump a letter, or tap the letter row.

  2. Favourites

    B stars the cart under the caret.
    Hold B to show only your favourites.

  3. Pick an Emulator

    Press START to open a GBA cart.
    Left and Right swap the core "chip" between mGBA and gpSP.
    A saves your choice.

  4. Insert and Play

    Tapping A loads the last save state.
    Holding A starts the game fresh.

  5. The Pause Menu

    Tap MENU at the top centre of the screen, or use Android's Back gesture.
    Save or load a state, browse states, change core, controls, screen, cheats and achievements.
    B closes it.

  6. Ejecting a Game

    Hold MENU for a second, or pick Back to Shelf in the pause menu.
    With Auto Save on Eject on, slot saves a state on the way out.

  7. Save States

    SELECT + R creates a save state.
    SELECT + L loads the most recent.
    Browse States in the pause menu flicks through them all.

  8. Fast-Forward and Rewind

    Hold R2 to fast-forward.
    Double tap R2 to lock it on.
    Hold L2 to rewind.

  9. On-Screen Controls

    Controls in the pause menu sets their opacity and size, touch haptics, vibration strength, and what X and Y do.
    Pick up a gamepad or keyboard and they hide; touch the screen and they're back.

  10. Fold and Unfold

    slot follows the screen as you fold or unfold, without restarting the game.
    On the wide cover screen the controls sit beside the picture; unfolded, they float over it.

  11. Commit Aspect Ratio Crimes

    Just like upstream, L stretches GB and GBC games.
    R puts them back to their original size.

  12. Screen

    SELECT + B / A changes the shader.
    SELECT + Y toggles color correction.
    The Screen page also has color grades, shader strength and frame blending.

  13. Game Boy Palettes

    Turn on GB Palettes in the Screen settings.
    SELECT + L2/R2 steps through them.

  14. Edit Cart

    In the shelf menu, Edit Cart changes the shell colour, finish and outline of the cart under the caret.
    Picture puts a photo from your gallery on the label; Text types your own words.
    Back to default undoes it.

  15. Cheats

    Put codes in Cheats/<rom name>.txt, one CODE # name per line.
    Switch them on from Cheats in the pause menu. mGBA core only.

  16. RetroAchievements

    Sign in from Achievements in the shelf menu.
    Changes apply to the next game you start. Unlocks made offline sync later.

  17. Library

    Library in the shelf menu backs up and restores your saves, states, cheat toggles and cart colours, and imports games from Download.

  18. Settings

    MENU on the shelf opens the shelf menu: favourites, Edit Cart, Screen, Gameplay, Achievements, Library, Date & Time and About.

Anticipated Questions Answered

Which devices does it run on?
DeviceStatusSince Version
Samsung Galaxy Z Fold 7Tested1.0.0
Other arm64 phones and foldables, Android 8.0+Should work, untested1.0.0

Tried it on something else? Open an issue and say how it went, including the screen's aspect ratio.

How is this different from slot?
It's the same shelf, carts, cores, saves and states, built for a touchscreen: on-screen controls, a pause menu, Edit Cart, Library, phone vibration, and layouts that follow a foldable. It also adds RetroAchievements, cheats, colour grades and LaunchBox labels, adapted from community forks.
Can I link two phones?
Not yet. Link play is left out of this release; a Wi-Fi link that works on phones is in development.
Where do my files live?
In /sdcard/slot/: Games, Saves, States, Labels, Cheats, Config, Backups, BIOS, System and Wallpapers.
Will it run anything other than GB, GBC and GBA?
No. Like upstream, it's about the feeling of a Game Boy, not a do-everything emulator.
Where do the cart labels come from?
When the phone is online, slot fetches missing labels from LaunchBox in the background.
Can I use my own labels?
Drop a .png into the Labels/ folder for that platform, named after the ROM. For example, Labels/GBA/Metroid Fusion.png matches Games/GBA/Metroid Fusion.gba. Or use Edit Cart › Picture to put a photo from your gallery on the label.
Does it work with Cart Studio?
Yes. Edit Cart writes Labels/cart_shell.txt, the same file the slot Cart Studio produces, so either can set a cart's shell.
Where do games go?
Each platform has its own folder under /sdcard/slot/Games/. Or import them from Download with Library.
I added games and they don't show up.
The shelf is built when the app starts. Close slot and open it again. Make sure they're unzipped and in the right platform folder.
Is there a BIOS boot animation on game start?
Yes! Drop the following files you legally obtained into BIOS/.
  • gba_bios.bin
  • gbc_bios.bin
  • gb_bios.bin
Where do the games come from?
Your own legally obtained backups.
Does my backup include my RetroAchievements login?
No. Backups hold Saves, States, Cheats and Labels/cart_shell.txt, and leave out Config/ on purpose.
How do I add cheats?
Create Cheats/<rom name>.txt with one CODE # name per line, then switch them on from Cheats in the pause menu. Cheats need the mGBA core; gpSP has none.
How do I sign in to RetroAchievements?
Shelf menu › Achievements. Enter your username and password on the on-screen keyboard. Changes apply to the next game you start.
Upstream said no to achievements and cheats. Why are they here?
This is a fork, and forks can add things. The designs come from pvaibhav's and RetroGame66's forks, rebuilt for slot's own structure.
Where do I report a bug?
On this repository's issues. Please don't file Android bugs on upstream slot's tracker; it has nothing to do with this port.
What should I include?
Your phone model and Android version, the slot version from About, what you did and what happened. A screen recording helps a lot.

Credits

slot is by Brandon T. Kowalski, under GPL-3.0-or-later. Everything here is built on that code; the Android shell, touch controls, pause menu, storage and power glue are the port.

pvaibhav's fork provided the RetroAchievements integration, the LaunchBox cartridge-art fetcher and the frame-blending idea. RetroGame66's fork provided the designs for cheat codes, colour grades and panel-mask presets, plus the favourites and letter-index ideas.

Emulation is handled by mGBA and gpSP. rcheevos powers achievements. Cart labels come from LaunchBox.

Type is Open Sans, under the SIL Open Font License, and Nerd Fonts symbols by Ryan L. McIntyre, under MIT. The panel mask is derived from LCD3x, a public-domain shader by Gigaherz in the libretro shader collection. The Dot and Simpletex screen shaders are ports of Dot by Themaister and simpletex_lcd by jdgleaver from the same collection.

The cart sounds are upstream's recording of a cartridge going into a childhood GBA.

Game Boy is a trademark of Nintendo. slot for Android is not affiliated with Nintendo.
